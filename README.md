# AK Yalıtım website

Turkish-language website for AK Yalıtım Hizmetleri, based on the public Instagram profile information: İstanbul Avrupa Yakası, free inspection, phone 0538 052 44 92, and @ak.yalitim.

## Run locally

- `npm install`
- `npm run dev`
- Open http://localhost:3000

## SEO launch checklist

- The canonical domain is configured as `https://xn--akyaltm-vfbb.com` (the ASCII/Punycode form of `https://akyalıtım.com`). Add the same value as `NEXT_PUBLIC_SITE_URL` in the Vercel Production environment before deployment.
- Verify the domain in Google Search Console and Bing Webmaster Tools, then submit `/sitemap.xml`.
- Create/claim the Google Business Profile and use the exact same business name, phone, service area, and website. Add the real address only if customers are served there.
- Replace/confirm service details and geographic coverage with the business owner. Add real, permission-cleared project photographs with descriptive alt text when available. Do not publish invented testimonials, guarantees, or project statistics.
- Ensure the phone, WhatsApp, and domain are correct, and add the site to relevant local directories consistently.

Technical SEO included: Turkish metadata, canonical URL, Open Graph tags, robots and sitemap routes, semantic page headings, mobile-friendly layout, and LocalBusiness/FAQ structured data.

Search ranking is not guaranteed by any SEO configuration. First-page visibility depends on the verified domain, content quality, local authority, reviews, competition, and ongoing maintenance.
